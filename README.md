# 📈 Sales Prediction using Machine Learning

## 📌 Project Overview
This project predicts sales based on advertising expenditure using Machine Learning and Linear Regression.

## 📊 Project Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Train-test split
- Linear Regression model
- Sales prediction
- Model evaluation using R² Score
- Data visualization

## 📂 Dataset
Advertising Dataset containing:
- TV Advertising
- Radio Advertising
- Newspaper Advertising
- Sales

## 📈 Data Visualizations
- Actual vs Predicted Sales
- Error Distribution
- Feature Coefficients
- Correlation Heatmap
- Pairplot

## 🤖 Machine Learning Algorithm
Linear Regression

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🎯 Project Outcome
Developed a Machine Learning model to predict sales using advertising expenditure across different marketing channels.
